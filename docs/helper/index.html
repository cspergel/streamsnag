StreamSnag/Helper

The StreamSnag helper

A small program on your computer for the jobs a browser can't do by itself. StreamSnag's downloader works without it; the helper makes it better.

What it adds

  • One file: joins a video's picture and sound into one MP4, where a site sends them apart.
  • Any folder: saves where you choose, not only into Downloads.
  • Converting: turns a video into MP3 or another format.
  • Pro: turns a lecture's speech into text on your own computer, and can use an AI subscription you already have.

Windows

  1. Download it

    Download the helper for Windows 33 MB

  2. Set it up

    Open the zip and double-click Set up StreamSnag helper.cmd. It brings everything it needs, offers to install ffmpeg, and needs no admin rights.

    The first time, Windows may say it protected your PC from an unknown publisher: choose More info, then Run anyway. If setup asks for StreamSnag's ID, copy it from StreamSnag's Settings, under Local helper.

  3. Check it

    Restart the browser, open StreamSnag's Settings, choose Local helper and press Check helper.

macOS and Linux

  1. Have Node.js

    The helper runs on Node.js 20 or newer. For joining and converting it also needs ffmpeg: on a Mac, brew install ffmpeg; on Linux, your package manager's ffmpeg.

  2. Download it

    Download the helper for macOS and Linux 42 KB

    Unzip it into a folder you will keep, such as your home folder, not Downloads: the browser runs the helper from there.

  3. Set it up

    Open a terminal in that folder and run node install.js --id followed by StreamSnag's ID, which StreamSnag's Settings show under Local helper. Then restart the browser and press Check helper there.

Good to know

  • A new version: set it up again the same way. It takes the place of the old one.
  • To remove it: on Windows, Settings, Apps, Installed apps, StreamSnag helper. On macOS and Linux, run node install.js --uninstall in its folder, then delete the folder.
  • It only answers StreamSnag: the browser starts it for StreamSnag alone, and no other extension or website can reach it.
  • Something wrong? Write to support@streamsnag.app with what you see after pressing Check helper.
