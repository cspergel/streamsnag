Files

Any folder on your PC, e.g. D:\Videos. Chrome can only save inside Downloads, so the local helper moves each finished file here right after it is merged.

Use / for nested folders. Tokens: {site} {course} {date} {kind}. Example: StreamSnag/{site} makes one folder per website, and StreamSnag/{course} one per course.

Tokens: {title} (the lecture/episode name found on the page) {course} {page} (tab title) {quality} {host} {date} {kind}. Example: {course} - {title}

Videos you already have

StreamSnag looks through these folders (and their subfolders) to mark videos as downloaded. It matches by file size, length, the video's id in the name, or the video's own name, so renamed files and files saved by other tools count too. Your save folder and wherever StreamSnag saved before are always checked.

    Detection & streams

    StreamSnag never downloads DRM-protected (Widevine/PlayReady/FairPlay) or encrypted streams. Only save content you have the right to keep.

    Local helper

    A small Node.js program Chrome starts on demand (native messaging). It unlocks: your Claude subscription for AI, ffmpeg merging/conversion, and yt-dlp downloads for sites the browser can't handle.

    1. Install Node.js (18+). For AI via subscription: npm i -g @anthropic-ai/claude-code and run claude once to sign in.
    2. Optional: install ffmpeg and yt-dlp (e.g. winget install Gyan.FFmpeg yt-dlp.yt-dlp).
    3. In the project folder run npm run install-helper, then restart Chrome.

    Site recipes

    Recipes are small JSON rule sets (CSS selectors, regexes, same-site fetches) that find media on a specific site. “Find with AI” writes them for you; you can edit them here. They are data only — never code.
